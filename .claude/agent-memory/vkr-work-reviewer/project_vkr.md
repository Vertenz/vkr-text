Тема ВКР: «Исследование и разработка веб-приложения для совместного учёта расходов»

Направление: 09.04.02 «Информационные системы и технологии», профиль «Веб-разработчик».

Требования: методическое пособие 2024 г. (codex.md + PDF методички).

Структура работы:
- Введение
- Глава 1: теоретическая часть (§1.1–§1.7)
- Глава 2: практическая реализация (бэкенд, фронтенд, инфраструктура, тестирование)
- Заключение
- Список литературы
- Приложения

Цель работы: исследование архитектурных подходов и разработка полнофункционального веб-приложения для совместного учёта расходов.

Задачи (8 штук): анализ предметной области → сравнительный анализ → выбор архитектуры → проектирование → финансовая модель → реализация → инфраструктура → тестирование.

Технологический стек: FastAPI, PostgreSQL, RabbitMQ, Docker Compose, Nuxt 4, Nginx, api-gateway.
