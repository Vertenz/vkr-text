## Использование абсолютных слов

«Гарантирует/исключает» используется только в контексте конкретных технических механизмов с реальной строгой гарантией:
- CHECK-ограничения PostgreSQL (положительность сумм, неравенство from≠to);
- транзакционная атомарность БД (либо обе записи зафиксированы, либо ни одна);
- FK-каскады (целостность ссылок);
- целочисленная арифметика (исключает ошибки округления);
- частичный уникальный индекс (исключает гонку);
- ACME-агент (исключает ручное управление сертификатами).

Превышений нет: вероятностные гарантии оформлены мягче — «не более», «снижает риск», «ограничивает».
